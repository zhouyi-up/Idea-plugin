# 弹出窗口使用

弹出窗口需要使用插件API主动弹出，主要使用到API如下
```java
JBPopupFactory jbPopupFactory = JBPopupFactory.getInstance();
```
主要方法：

1. createComponentPopupBuilder()
```java
jbPopupFactory.createComponentPopupBuilder(xxx, xxx);
```
2. createPopupChooserBuilder()
```java
jbPopupFactory.createPopupChooserBuilder(xxx);
```
3. createConfirmation()
```java
jbPopupFactory.createConfirmation(xxx,xxx,xxx)
```
4. createActionGroupPopup()
```java
jbPopupFactory.createActionGroupPopup()
```

显示：
```java
JBPopup popup = componentPopupBuilder.createPopup();
popup.show(this);
```
